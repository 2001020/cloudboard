# CloudBoard 26.x（C++ 版）功能与界面盘点

本文档用于 27.0 Rust 重写时对照，路径指向 `legacy/cpp/src/`。尺寸为基础像素（×DPI/96）。
标记 **[死代码]** 的功能在旧版里有实现但没有任何入口调用。

## 1. 底栏（`UI.cpp:631-1017`）
- 高 60，无顶栏。
- 左侧 4 个按钮（44 宽，间距 6，圆角 8）：退出（红色调）、回中、最小化、设置。
- 毛玻璃面板：从设置按钮右侧 +8 到窗口右侧 −5，高 50，圆角 14，竖向渐变（强调色混入）。
- 中间组（50×40，间距 3）：打开、保存、缩放（标签为百分比）、拖动、画笔（下拉 + 当前颜色点）、橡皮（下拉 + 尺寸）、选择、撤销、重做。教具按钮被注释掉。
- 右侧翻页：`<`、页码 n/N、`>`；非 PDF 模式下还有 `+`、`−`。
- 旧版问题：页码点击没有处理；PDF 模式仍为 `+/−` 留空位；窄窗口时各组重叠。
- 主题：深色窗口背景 (24,28,40)，浅色 (235,238,242)，白板为白色；6 种强调色：蓝、紫、绿、橙、红、青。

## 2. 弹窗与对话框
- 所有底栏弹窗水平居中，位于底栏上方 8。
- 画笔（330×130）：8 色（黑、红、橙、黄、绿、蓝、紫、白），粗细 {2,4,8,14,24}，线型（实线 / 虚线 / 点线）。荧光笔和形状识别为 [死代码]。
- 橡皮（330×70）：大小滑块 5–80，“清屏”按钮（可撤销）。
- 缩放（460×50）：50/75/100/150/200/300/350%；双指捏合可缩放到 25–350%。
- 教具（被禁用）：45° 三角板、30° 三角板、圆规、隐藏。
- 选择弹窗：只能右键打开，触控用户无法使用；包含复制（原位 +20 偏移）、删除、8 色改色。
- 设置（440×480）：
  - 界面颜色：深色 / 浅色 / 跟随系统
  - 强调色 6 选 1
  - 启动加载画面开关
  - 检查更新
  - 版本号
  - 重置所有设置、关闭
- `settings.json`：`colorTheme`、`themeColor`、`showSplash`、三角板/圆规的位置和角度。画笔颜色和粗细不保存。
- 确认框：
  - 退出：“退出前是否保存当前白板？”，选项为保存并退出 / 不保存退出 / 取消
  - 删除页：“确定删除当前页？”
  - 重置设置：“确定重置所有设置至默认值？”
- 加载遮罩：进度条和 “n / N (x%)”，没有取消按钮。
- 文件浏览器为 [死代码]，实际使用系统打开对话框（cloudboard / pdf / 图片 / 所有文件）。
- 提示条：画板顶部居中，显示 3 秒。

## 3. 白板行为
- 笔画：
  - 按最小间距去点，近似共线的点合并
  - 绘制时用 Catmull-Rom 平滑，遇到长段或急转弯时不平滑
  - 80ms 间隔后的大跳跃会自动断笔
  - 不采集压力，线宽恒定
  - 450ms 内的连续笔画合并为一步撤销
- 橡皮：按圆与线段求交来切分笔画；形状笔画整笔删除；不擦文字和图片。
- 文字：只能按 `T` 键在视图中心添加（缩放下位置有 bug）；Enter 提交，Shift+Enter 换行；不能再次编辑已有文字。
- 图片：拖放、打开对话框或命令行导入，最长边缩放到 ≤600。
- 选择：框选、点选文字/图片、拖动移动、Delete 删除、改色。Ctrl+C 可用，Ctrl+V 为 [死代码]。
- 页面：最多 56 页；在最后一页按“下一页”会新增页面；删除页需确认；鼠标滚轮翻页。
- PDF：
  - 超过 50 页的文件直接拒绝
  - 各页纵向拼接成连续画布，以 2× 分辨率渲染
  - 前 8 页在加载遮罩下同步渲染
  - 当前页 ±8 之外的页面被淘汰
  - 批注保存在拼接后的绝对坐标中
  - 窗口尺寸改变时会同步重新渲染全部页面，并清掉用户插入的图片（bug）
- 导出 PNG 和自动保存为 [死代码]。

## 4. 教具（整体被 `kAssistToolsEnabled=false` 禁用）
- 三角板刻度每 12 单位一格，数字与 “cm” 标注不符；没有量角器。
- 圆规用笔尖既画弧又调半径，所以在画笔工具下无法调半径。
- 双指旋转/缩放的代码被 `if (false && …)` 关闭；命中测试没有考虑内部镂空区域。

## 5. 计时器（[死代码]）
- `ShowTimerPanel` 从未被调用。
- 秒表的计数写在倒计时的定时器分支里，单独启动秒表时不会走。
- “暂停”按钮是乱码 “鏆傚仠”。
- 倒计时和秒表共用一个显示。
- 靠 1 秒 tick 累计，会漂移。
- 到时只有一声 `MessageBeep`。
- 不做 DPI 缩放，每次打开泄漏两个 HFONT。
- 输入框控件 ID 600 与“回中”命令冲突：在框里输入时画板会回中。

## 6. 触控
- 三指及以上：切换到橡皮。
- 双指：捏合缩放，没有平移。
- 单指：模拟为鼠标。
- 不区分笔和手指，没有防误触，不采集压力。

## 7. 快捷键与系统集成
- 快捷键：
  - Ctrl+Z / Ctrl+Y：撤销 / 重做
  - Ctrl+S：保存
  - Ctrl+C：复制
  - ← / → / PgUp / PgDn：翻页
  - Esc：关闭弹窗
  - Delete：删除所选
  - 1–4：拖动 / 画笔 / 橡皮 / 选择
  - T：添加文字
- 命令行参数：`/uninstall`，或一个文件路径（.cloudboard / .pdf / 图片）。
- 文件关联（HKCU）：`.cloudboard` 设为默认程序，`.pdf` 加入“打开方式”列表。
- 无边框全屏窗口。
- 启动窗：420×220，蓝色背景 (33,87,173)，几何装饰，“Cloudboard 26” 滑入动画，最短显示 1.6 秒；字体在启动窗创建之后才加载。

## 8. `.cloudboard` v1 格式（`ProjectIO.cpp`）
- 小端序，紧凑排列。
- 字符串为 `u32 n` 后跟 n 个 UTF-16 码元；blob 为 `u64 n` 后跟字节；颜色为 ARGB `u32`。
- 文件头：`u32 0x42444C43`，`u32 version=1`，`u32 0x01020304`。
- 之后是若干块：`u32 type`，`u64 len`，payload。
- META 块：appVersion、pdfPath、u8 pdfMode、i32 page、f32 zoom、f32 scrollX、f32 scrollY、u64 nextUid、f32 pdfPageWidth、f32 pdfTotalHeight、userName。
- PDF_DATA 块：path、内嵌的整个 PDF。
- PAGES 块：页数，然后每页依次为：
  - 笔画：uid、argb、width、style、flags（bit0 荧光笔，bit1 形状）、shape、ax/ay/bx/by，再跟 n 个点 {i32 dx, i32 dy, u16 压力×1024, u16 dtMs}。点坐标 ×100 后差分编码，首点为绝对坐标。
  - 文字：uid、text、x、y、argb、size、family、u8 bold。
  - 图片：uid、x、y、w、h、rot，再跟 PNG 数据。PDF 模式下 `images[0]` 是页面位图，保存时跳过。
- ASSIST 块：kind、triangleKind、以及 8 个 f32（三角板和圆规的位置、角度、缩放/半径）。
